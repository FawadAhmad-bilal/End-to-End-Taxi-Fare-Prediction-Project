📌 Project Overview

This project uses the Seaborn taxis dataset to analyze taxi trip data and build a machine learning model for predicting ride totals.

✨ Features
Data cleaning and preprocessing
Missing value handling
Feature encoding using Label Encoding
Exploratory Data Analysis (EDA)
Data visualization with Matplotlib & Seaborn
Machine Learning model training
Model evaluation using R² Score, MAE, and RMSE
🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook
📂 Workflow
Load and explore dataset
Clean missing values
Remove unnecessary columns
Encode categorical features
Visualize patterns and distributions
Train regression model
Evaluate model performance
📊 Machine Learning

The project applies regression algorithms to predict taxi fare totals based on trip-related features.

🚀 How to Run
pip install pandas numpy matplotlib seaborn scikit-learn

Run the notebook:

jupyter notebook
